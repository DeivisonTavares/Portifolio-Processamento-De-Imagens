# Portfolio - Processamento de Imagens

Este repositório foi desenvolvido para armazenar os códigos, atividades e projetos práticos realizados durante a disciplina de **Processamento de Imagens**.

---

## 📂 Estrutura do Repositório

O escopo do projeto é **`Portifolio-Processamento-De-Imagens`** e sua organização está dividida nas seguintes pastas:

* 📁 **`Aulas/`**: Scripts e exercícios práticos desenvolvidos durante as aulas.
* 📁 **`ParaCasa/`**: Atividades para casa e projetos.

---

## 🛠️ Tecnologias e Ferramentas

- **Linguagem:** Python
- **Bibliotecas Principais:** NumPy, Matplotlib, OpenCV
- **Ambiente:** Jupyter Notebook / VS Code / Google Colab
